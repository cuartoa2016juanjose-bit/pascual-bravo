##  Gestión de Bases de Datos
Implementación de soluciones de persistencia de datos siguiendo estándares industriales.

- **Modelado:** Diseño robusto de diagramas **MER (Entidad-Relación)** y paso al modelo relacional.
- **Lenguaje SQL:**
  - **DDL (Data Definition Language):** Creación y alteración de esquemas (Tables, Constraints, Indexes).
  - **DML (Data Manipulation Language):** Consultas complejas, inserciones masivas y optimización de actualizaciones.
- **Proyecto Final:** Desarrollo de una base de datos institucional completa con integridad referencial.

---

##  Estructuras de Datos Avanzadas
Implementación de algoritmos eficientes y gestión de memoria.

| Categoría | Conceptos Implementados |
| :--- | :--- |
| **Fundamentos** | Recursividad, Arreglos multidimensionales, Punteros (C++). |
| **Dinámicas Lineales** | Listas Enlazadas (Simples/Dobles), Pilas (Stacks) y Colas (Queues). |
| **No Lineales** | Árboles Binarios (BST), Grafos y algoritmos de búsqueda (BFS/DFS). |
| **Análisis** | Cálculo de **Complejidad Algorithmic (Big O)** para optimización de recursos. |

##  Matemáticas Discretas
La base lógica de la computación.

* **Lógica:** Proposicional y cuantificacional aplicada a condiciones de código.
* **Teoría de Conjuntos:** Operaciones fundamentales para el manejo de colecciones.
* **Arquitectura Lógica:** Implementación y simplificación de **Compuertas Lógicas**.

---

##  Sistemas Operativos
Comprensión del entorno de ejecución y gestión de hardware.

* **Gestión de Procesos:** Planificación de CPU, concurrencia y estados del proceso.
* **File System:** Jerarquía de archivos, gestión de permisos vía terminal y administración de medios de almacenamiento.
* **Shell Scripting:** Automatización de tareas básicas en consola.

---

##  Desarrollo y Modularización (Python)
Aplicación práctica de lenguajes de alto nivel con enfoque en ciencia de datos y lógica.

* **Lógica de Programación:** Secuencias, matrices y manipulación avanzada de caracteres.
* **Matemática Aplicada:** Funciones de estadística básica y teoría de números.
* **Arquitectura:** Organización modular de proyectos para garantizar escalabilidad y legibilidad del código.
